# From-GEO-Discovery-to-TCGA-Validation-A-Five-Gene-Prognostic-Signature-for-Colorectal-Cancer
Complete workflow for a five-gene CRC prognostic signature. Discovery using GEO datasets, validation with TCGA-COAD/READ. Includes differential expression, Cox/LASSO regression, KM survival curves, time-dependent ROC, and risk assessment. Independent prognostic value demonstrated.
